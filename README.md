# Bobr Checker

Центральный мониторинг VPN-локаций BobrGO на отдельном VPS. Поддержка множественных групп подписок (для себя и друзей), раздельные API для ботов, Docker Compose, публичный HTTPS через Caddy и автоматические TLS-сертификаты Let's Encrypt.

## Требования

- Ubuntu или Debian, архитектура x86_64/ARM64
- Домен с DNS A-записью на публичный IPv4 этого VPS
- Доступные извне TCP 80 и TCP 443; UDP 443 рекомендуется для HTTP/3
- Ссылки подписок Remnawave / Xray

## Установка — в один запуск

```bash
git clone https://github.com/I22rusIBarney/bobr-checker.git
cd bobr-checker
sudo bash install.sh
```

Установщик попросит:
1. Домен панели, например `monitor.example.com`
2. Ссылку на подписку

Дальше он автоматически:
- установит Docker Engine и Docker Compose;
- проверит DNS и порты 80/443;
- настроит правила UFW (если активен);
- запустит изолированные чекеры для каждой группы подписок и Caddy;
- выведет реквизиты доступа.

## Мульти-группы и раздельные API для ботов

Вы можете раздавать разные ссылки мониторинга для себя и друзей.
Для быстрой настройки ссылок выполните:

```bash
sudo bcheck config
```

Команда запросит ссылки для групп и выведет готовые адреса для ваших ботов:
- **Ваша группа:** `https://monitor.example.com/api/my/api/v1/public/proxies`
- **Группа Друга 1:** `https://monitor.example.com/api/friend1/api/v1/public/proxies`
- **Группа Друга 2:** `https://monitor.example.com/api/friend2/api/v1/public/proxies`
- **Основная веб-панель:** `https://monitor.example.com/`

## Управление

```bash
bcheck status    # Статус контейнеров
bcheck logs      # Логи чекеров
bcheck restart   # Перезапуск
bcheck config    # Интерактивная настройка ссылок подписок
bcheck update    # Обновление чекера до последней версии из GitHub
```

## Фильтры отображения

В веб-интерфейсе закреплена кнопка **«Хосты»**:
- по умолчанию автоматически скрываются служебные карточки и группы балансировщиков `АВТО-ВЫБОР` / `AUTO-SELECT`;
- доступны гибкие RegEx-маски для групп и серверов прямо в настройках интерфейса;
- переключатель подсчёта скрытых хостов в общей статистике (Total / Online / Offline);
- настройки сохраняются в браузере (localStorage).
